# মাদরাসা ম্যানেজমেন্ট

ছাত্র তালিকা (জামাত অনুযায়ী), বেতন ও বিদ্যুৎ বিল, পরীক্ষার ফি এবং সাময়িক পরীক্ষার ফলাফল সীট (PDF ডাউনলোডসহ)।

## ফাইল
| ফাইল | কাজ |
|---|---|
| index.html | পুরো অ্যাপ |
| manifest.json | ফোনের হোম স্ক্রিনে অ্যাপ হিসেবে বসানোর তথ্য |
| sw.js | ইন্টারনেট ছাড়াও অ্যাপ চালানোর জন্য |
| icon-192.png, icon-512.png | অ্যাপের আইকন |
| SutonnyOMJ.ttf | (আপনার কাছে থাকলে) ফলাফল সীটের ফন্ট, একই ফোল্ডারে দিন |

## GitHub Pages-এ চালু করার নিয়ম
1. GitHub-এ নতুন রিপোজিটরি বানান (Public)।
2. **Add file → Upload files** দিয়ে ওপরের সব ফাইল একসাথে আপলোড করে **Commit** করুন।
3. **Settings → Pages** এ গিয়ে Source: **Deploy from a branch**, Branch: **main**, Folder: **/ (root)** দিয়ে Save করুন।
4. এক-দুই মিনিট পর লিংক পাবেন: `https://আপনার-ইউজারনেম.github.io/রিপোজিটরির-নাম/`
5. ফোনের Chrome-এ লিংক খুলে মেনু থেকে **Add to Home screen / Install app** দিন।

## মনে রাখার বিষয়
- ছাত্র, বিল ও ফলাফলের সব ডাটা শুধু ওই ফোনের ব্রাউজারে সেভ থাকে, GitHub-এ যায় না। ব্রাউজারের ডাটা মুছলে ডাটাও মুছে যাবে।
- এক ফোনের ডাটা অন্য ফোনে দেখা যাবে না।
- PDF/JPG ডাউনলোডের লাইব্রেরি প্রথমবার ইন্টারনেট থেকে নামে, পরে অফলাইনেও চলে।
- ভবিষ্যতে কোড বদলালে নতুন index.html আপলোড করুন। পরিবর্তন দেখতে অ্যাপটা একবার বন্ধ করে খুলতে হতে পারে।
